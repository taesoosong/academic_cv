# Taesoo Song — curriculum vitae

Source and publishing workflow for Taesoo Song's academic CV.

The CV is maintained in \`song_taesoo_cv.tex\`. Pushes are checked by GitHub
Actions, and the publishing workflow builds \`CV_SONG_Taesoo.pdf\` for GitHub
Pages.

## Build locally

With Tectonic installed:

\`\`\`sh
tectonic song_taesoo_cv.tex
\`\`\`
